## ❌ 常见错误操作

### 错误1：重复点击授权按钮

```
❌ 错误流程：
点击授权 → 微信弹出框 → 点击"允许"
↓
再次点击授权按钮 ← 错误！
↓
微信返回相同code（已失效）
↓
后端报错："授权码已失效"
```

**解决方案**：
- ✅ 等待登录完成
- ✅ 如果失败，等待2秒后再点击
- ✅ 每次授权都会获取新code

---

### 错误2：连续快速点击

```
❌ 错误流程：
快速点击授权按钮多次
↓
微信返回多个相同code
↓
后端处理第一个成功
↓
后续请求报错："code已失效"
```

**解决方案**：
- ✅ 添加了防重复点击机制（2秒内只能点一次）
- ✅ 点击一次后等待结果

---

### 错误3：取消授权后又点击

```
❌ 错误流程：
点击授权 → 微信弹出框 → 点击"拒绝"
↓
立即再次点击授权 ← 可能有问题
↓
微信可能返回相同结果
```

**解决方案**：
- ✅ 等待2秒后再点击
- ✅ 清除错误提示后再试

## 🐛 问题排查

### 问题：真机调试仍报"code已失效"

**排查步骤**：

1. **检查是否重复点击**
   - vConsole → Log → 查看"防止重复点击"日志
   - 确认只点击一次

2. **检查网络请求**
   - vConsole → Network → 查看 `/wechat-phone-login` 请求
   - 查看请求参数和响应

3. **清除缓存重试**
   ```
   vConsole → System → Storage → Clear
   重新点击授权按钮
   ```

4. **等待一段时间**
   - 微信缓存需要时间清除
   - 等待10-20秒后再试

5. **重启真机调试**
   ```
   关闭真机调试 → 重新打开 → 扫码连接
   ```
