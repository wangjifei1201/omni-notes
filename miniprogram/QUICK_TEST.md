## 🐛 如果还是报错

### 查看详细错误信息

1. 手机上打开 vConsole（右下角绿色图标）
2. 点击 **"Network"** 标签
3. 查看失败的请求
4. 查看状态码和响应内容

### 常见错误排查

#### 错误: `request:fail`

**原因**: API 地址无法访问

**解决**:
```bash
# 确认手机和电脑在同一局域网
ping 192.168.1.187

# 确认后端运行
curl http://192.168.1.187:8000/api/v1/health
```

#### 错误: 404 Not Found

**原因**: 接口不存在

**解决**: 查看后端日志
```bash
tail -20 backend/backend.log
```

#### 错误: 401 Unauthorized

**原因**: Token 过期或未登录

**解决**: 
- 清除本地存储：vConsole → System → Storage → Clear
- 重新登录
