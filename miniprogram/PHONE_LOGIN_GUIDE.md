# 微信小程序手机号登录实现指南

## 功能概述

已实现微信小程序的手机号自动授权登录模式，包括：
1. **微信授权一键登录** - 使用微信授权快速获取手机号
2. **手机号验证码登录** - 传统的手机号+验证码登录方式
3. **邮箱密码登录** - 保留原有的邮箱登录方式

## 前端实现

### 登录页面结构

#### 1. 登录模式选择
- 手机号登录（默认）
- 邮箱登录

#### 2. 手机号登录流程

**方式一：微信授权一键登录**
```
用户点击"一键授权登录"
  ↓
微信弹出授权确认框
  ↓
用户确认授权
  ↓
获取 code、encryptedData、iv
  ↓
发送到后端进行解密和登录
  ↓
返回用户信息和token
  ↓
保存到本地存储
  ↓
跳转到首页
```

**方式二：手机号+验证码登录**
```
用户输入手机号
  ↓
点击"获取验证码"
  ↓
后端发送验证码到手机
  ↓
用户输入验证码
  ↓
点击"登录"
  ↓
后端验证验证码
  ↓
返回用户信息和token
  ↓
保存到本地存储
  ↓
跳转到首页
```

## 后端实现需求

### 新增API端点

#### 1. 发送手机号验证码
```
POST /api/v1/auth/send-phone-code
请求体：
{
  "phone": "13800138000"
}
响应：
{
  "message": "验证码已发送"
}
```

#### 2. 手机号验证码登录
```
POST /api/v1/auth/phone-login
请求体：
{
  "phone": "13800138000",
  "code": "123456"
}
响应：
{
  "id": "user_id",
  "username": "用户名",
  "email": "email@example.com",
  "phone": "13800138000",
  "is_guest": false,
  "token": "jwt_token",
  "created_at": "2024-04-14T11:17:04+08:00"
}
```

#### 3. 微信授权登录
```
POST /api/v1/auth/wechat-phone-login
请求体：
{
  "code": "微信授权code",
  "encrypted_data": "加密的手机号数据",
  "iv": "初始化向量"
}
响应：
{
  "id": "user_id",
  "username": "微信用户",
  "email": "wechat@example.com",
  "phone": "13800138000",
  "is_guest": false,
  "token": "jwt_token",
  "created_at": "2024-04-14T11:17:04+08:00"
}
```

### 实现步骤

1. **验证码管理**
   - 生成6位随机验证码
   - 存储到Redis，设置5分钟过期时间
   - 通过短信服务发送验证码

2. **手机号验证码登录**
   - 验证手机号格式
   - 检查验证码是否正确
   - 查询或创建用户
   - 生成JWT token
   - 返回用户信息

3. **微信授权登录**
   - 使用微信提供的code获取session_key
   - 使用session_key解密encryptedData获取手机号
   - 查询或创建用户
   - 生成JWT token
   - 返回用户信息

## 前端API调用

### 在登录页中使用

```javascript
// 发送验证码
const { authApi } = require('../../utils/api');

await authApi.sendPhoneCode('13800138000');

// 手机号验证码登录
const user = await authApi.phoneLogin('13800138000', '123456');

// 微信授权登录
const user = await authApi.wechatPhoneLogin(code, encryptedData, iv);
```

## 安全考虑

1. **验证码安全**
   - 验证码5分钟过期
   - 同一手机号5分钟内最多发送3次
   - 验证码错误3次后锁定15分钟

2. **微信授权安全**
   - 验证code的有效性
   - 使用session_key解密数据
   - 验证签名

3. **Token安全**
   - 使用JWT token
   - 设置合理的过期时间
   - 支持token刷新

## 常见问题

**Q: 微信授权失败怎么办？**
A: 用户可以选择手机号+验证码的方式登录

**Q: 验证码没有收到？**
A: 检查手机号是否正确，可以重新获取验证码

**Q: 如何处理已有账户的绑定？**
A: 可以在个人中心添加绑定手机号的功能

**Q: 如何支持多个登录方式？**
A: 后端可以支持同一用户绑定多个登录方式
