# 微信手机号授权登录 - 测试指南

## ❓ 为什么报错 "invalid code"

### 错误原因

```
"登录失败: 400: 微信登录失败: invalid code"
```

**这是微信API的正常保护机制**：

| 原因 | 说明 |
|------|------|
| Code只能用一次 | 每个授权code只能使用一次，用过就失效 |
| Code有效期短 | 5分钟有效期，过期就失效 |
| 需要真实授权 | 只有真实微信授权才能获取有效code |

---

## ✅ 正确的测试方法

### 🎯 方法1：真机调试（推荐）

**步骤**：

1. **打开微信开发者工具**
   
2. **点击"真机调试"按钮**（不是预览）
   ```
   开发者工具顶部 → 真机调试 → 扫码连接
   ```

3. **手机微信扫码连接**
   - 手机打开调试模式
   - vConsole自动开启

4. **点击"微信手机号登录"**
   - 微信弹出真实授权框
   - 点击"允许"
   - 获取真实有效的code

5. **自动完成登录**
   - 后端接收真实code
   - 调用微信API成功
   - 解密手机号成功
   - 创建用户成功
   - 自动跳转首页

---

### 🎯 方法2：预览版测试

**步骤**：

1. **点击"预览"按钮**
   ```
   开发者工具顶部 → 预览 → 生成二维码
   ```

2. **手机微信扫码打开小程序**

3. **点击"微信手机号登录"**
   - 真实微信授权流程
   - 获取有效code

4. **完成登录**

---

### ❌ 为什么模拟器会失败

**开发者工具模拟器**：
- ❌ 不是真实的微信环境
- ❌ 获取的code是测试code（无效）
- ❌ 微信API会拒绝测试code

**解决方案**：
- ✅ 使用真机调试模式
- ✅ 或使用预览版测试

## 💡 常见问题

### Q1: 为什么真机调试也报错？

**检查点**：
- AppID是否正确：`wx4362fac7e5d92795`
- AppSecret是否正确：`abe1a6b18e3c3fb7271c98e2bc5d6715`
- 是否点击了微信授权框的"允许"
- code是否过期（5分钟内使用）

---

### Q2: 如何确认配置正确？

**验证步骤**：
```bash
# 查看配置
grep WECHAT backend/.env

# 应显示：
WECHAT_MINIAPP_APPID=wx4362fac7e5d92795
WECHAT_MINIAPP_SECRET=abe1a6b18e3c3fb7271c98e2bc5d6715
```

✅ 已确认配置正确

---

### Q3: 每次都要重新授权吗？

**说明**：
- 每次测试都会获取新的code
- 每个code只能用一次
- 这是微信的安全机制

---

### Q4: 登录后用户信息保存在哪里？

**存储位置**：
```javascript
wx.setStorageSync('auth_token', user.id)
wx.setStorageSync('user_id', user.id)
```
