### 4. 微信手机号登录接口

#### 接口定义
```
POST /api/v1/auth/wechat-phone-login
```

#### 请求参数
```json
{
  "code": "微信登录code",
  "encrypted_data": "加密的手机号数据",
  "iv": "解密算法初始向量"
}
```

#### 响应数据
```json
{
  "id": "用户ID",
  "phone": "手机号",
  "is_guest": false,
  "username": "微信用户_13800138000",
  "usage_count": 0
}
```

#### 实现流程
```
1. 调用微信 API 获取 session_key 和 openid
   → https://api.weixin.qq.com/sns/jscode2session
   
2. 解密手机号数据
   → 使用 WeChatDecrypt 工具
   
3. 查找或创建用户
   → 先通过 openid 查找
   → 再通过 phone 查找
   → 不存在则创建新用户
   
4. 创建 session
   → SessionService.create_session()
   
5. 设置 cookie
   → set_session_cookie()
```

## 🎯 实现要点

### 1. 微信 API 调用
```python
wx_url = "https://api.weixin.qq.com/sns/jscode2session"
params = {

```

### 2. AES 解密
- 使用 `cryptography` 库
- AES-CBC 模式
- Base64 编码
- PKCS7 填充

### 3. 用户查找逻辑
```
openid 存在 → 直接登录
openid 不存在 + phone 存在 → 绑定 openid
openid 不存在 + phone 不存在 → 创建新用户
```

### 4. Cookie 管理
- HttpOnly cookie
- session_id 存储在 cookie
- 7天有效期
