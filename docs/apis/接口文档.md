# Omni-Notes API 文档

## 概述

Omni-Notes 是一个 AI 驱动的视频分析和笔记管理 API 服务。支持哔哩哔哩和抖音视频的解析、分析和笔记管理。

**Base URL**: `/api/v1`

**认证方式**: Session Cookie (部分接口需要认证，标注 `**Authentication**: Required`)

## 1. 认证与用户 (Authentication & User)

### 1.1 用户注册

**Endpoint**: `POST /api/v1/auth/register`

**描述**: 注册新用户账号。如果是访客用户，会自动迁移其数据到新账号。

**认证**: 可选 (有访客 session 时会自动迁移数据)

**Request Body**:
```json
{
  "username": "string",    // 用户名，3-20字符
  "password": "string"     // 密码，至少6字符
}
```

**Response** (200):
```json
{
  "id": "string",
  "username": "string",
  "is_guest": false,
  "usage_count": 0,
  "created_at": "datetime",
  "last_login_at": null
}
```

**Error Response** (400):
```json
{
  "detail": "用户名已存在" | "密码格式不符合要求"
}
```

---

### 1.2 用户登录

**Endpoint**: `POST /api/v1/auth/login`

**描述**: 使用用户名和密码登录。

**Request Body**:
```json
{
  "username": "string",
  "password": "string"
}
```

**Response** (200):
```json
{
  "id": "string",
  "username": "string",
  "is_guest": false,
  "usage_count": 0,
  "created_at": "datetime",
  "last_login_at": "datetime"
}
```

**Error Response** (401):
```json
{
  "detail": "用户名或密码错误"
}
```

---

### 1.3 用户登出

**Endpoint**: `POST /api/v1/auth/logout`

**描述**: 登出当前用户，清除 session cookie。

**Response** (200):
```json
{
  "success": true,
  "message": "已登出"
}
```

---

### 1.4 创建访客用户

**Endpoint**: `POST /api/v1/auth/guest`

**描述**: 创建访客用户，访客用户有使用次数限制。

**Response** (200):
```json
{
  "id": "string",
  "is_guest": true,
  "usage_count": 0,
  "session_id": "string"
}
```

**备注**: 访客用户限制由 `guest_usage_limit` 配置决定。

---

### 1.5 获取当前用户信息

**Endpoint**: `GET /api/v1/auth/me`

**描述**: 获取当前登录用户的信息。

**认证**: Required

**Response** (200):
```json
{
  "id": "string",
  "username": "string",
  "is_guest": false,
  "usage_count": 0,
  "created_at": "datetime",
  "last_login_at": "datetime"
}
```

---

### 1.6 检查访客限制

**Endpoint**: `GET /api/v1/auth/check-guest-limit`

**描述**: 检查当前访客用户是否达到使用限制。

**认证**: Required

**Response** (200):
```json
{
  "is_guest": true,
  "has_reached_limit": false,
  "usage_count": 3,
  "limit": 10,
  "remaining": 7
}
```

---

### 1.7 修改密码

**Endpoint**: `POST /api/v1/auth/change-password`

**描述**: 修改当前用户密码。

**认证**: Required

**Request Body**:
```json
{
  "old_password": "string",
  "new_password": "string"
}
```

**Response** (200):
```json
{
  "success": true,
  "message": "密码修改成功"
}
```

**Error Response** (400):
```json
{
  "detail": "旧密码不正确" | "新密码格式不符合要求"

```

---

### 1.8 微信手机号登录（新API）

**Endpoint**: `POST /api/v1/auth/wechat-phone-login`

**描述**: 使用微信新版手机号快速验证 API 登录。

**Request Body**:
```json
{
  "code": "string"  // 手机号授权code
}
```

**Response** (200):
```json
{

  "phone": "string",
  "is_guest": false,
  "username": "微信用户_13800138000",
  "usage_count": 0,
  "session_id": "string"

```

| errcode | 说明 |
|---------|------|
| 40029 | 授权码已失效，请重新授权 |
| 40163 | 授权码已被使用，请重新授权 |

## 2. 视频解析 (Video Parsing)

### 2.1 解析B站视频

**Endpoint**: `GET /api/v1/videos/bilibili-short`

**描述**: 解析哔哩哔哩视频 URL，获取视频信息。支持短 URL 和完整 URL。

**认证**: Required

**Query Parameters**:
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| url | string | 是 | B站视频链接 |

**支持的 URL 格式**:
- 短链接: `https://b23.tv/xxxxx`
- 完整链接: `https://www.bilibili.com/video/BVxxxxx`
- AV链接: `https://www.bilibili.com/video/AVxxxxx`

**Response** (200):
```json
{
  "platform": "bilibili",
  "video_id": "string",
  "title": "string",
  "author": "string",
  "author_id": "string",
  "duration": 3600,
  "cover": "string",
  "original_url": "string",
  "desc": "string"
}
```

---

### 2.2 解析抖音视频

**Endpoint**: `GET /api/v1/videos/douyin`

**描述**: 解析抖音视频 URL，获取视频信息。

**认证**: Required

**Query Parameters**:
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| url | string | 是 | 抖音视频链接 |

**支持的 URL 格式**:
- 短链接: `https://v.douyin.com/xxxxx`
- 完整链接: `https://www.douyin.com/video/1234567890`

**Response** (200):
```json
{
  "platform": "douyin",
  "video_id": "string",
  "title": "string",
  "author": "string",
  "author_id": null,
  "duration": 60,
  "cover": "string",
  "original_url": "string",
  "desc": "string"
}
```

**注意**: 抖音解析可能受反爬虫机制影响。

---

### 2.3 自动解析视频

**Endpoint**: `POST /api/v1/videos/auto`

**描述**: 自动检测平台并解析视频 URL。支持 B站和抖音。

**认证**: Required

**Request Body**:
```json
{
  "url": "string"
}
```

**Response** (200): 同 `2.1` 和 `2.2`

---

### 2.4 解析视频（统一入口）

**Endpoint**: `POST /api/v1/videos/parse`

**描述**: 解析视频 URL 的主入口，与 `auto` 端点功能相同。

**认证**: Required

**Request Body**:
```json
{
  "url": "string"
}
```

## 3. 分析任务 (Analysis Tasks)

### 3.1 创建分析任务

**Endpoint**: `POST /api/v1/analysis`

**描述**: 提交视频进行 AI 分析。任务加入队列后异步处理。

**认证**: Required

**Request Body**:
```json
{
  "url": "string",
  "use_whisper": true,
  "whisper_model": "base",
  "analysis_type": "comprehensive",
  "custom_prompt": "string"
}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| url | string | 是 | 视频链接 |
| use_whisper | boolean | 否 | 是否使用 Whisper 转写 (默认: 系统配置) |
| whisper_model | string | 否 | Whisper 模型: tiny/base/small/medium (默认: 系统配置) |
| analysis_type | string | 否 | 分析类型: comprehensive/summary/key_points/chapters/mindmap/custom |
| custom_prompt | string | 否 | 自定义提示词 (当 analysis_type=custom 时使用) |

**Response** (200):
```json
{
  "task_id": "string",
  "platform": "bilibili",
  "video_id": "string",
  "title": "string",
  "author": "string",
  "cover": "string",
  "duration": 3600,
  "status": "queued",
  "queue_position": 3,
  "estimated_wait_seconds": 120,
  "created_at": "datetime"
}
```

**Status 状态说明**:
| status | 说明 |
|--------|------|
| queued | 等待处理 |
| running | 处理中 |

**Error Response** (429):
```json
{
  "detail": {
    "error": "QUEUE_FULL",
    "message": "当前分析任务过多，请稍后重试",
    "retry_after": 300
  }
}
```

---

### 3.2 获取任务进度（SSE）

**Endpoint**: `GET /api/v1/analysis/{task_id}/progress`

**描述**: 通过 Server-Sent Events 获取实时进度更新。

**认证**: Required

**SSE 事件类型**:
| 事件 | 说明 |
|------|------|
| ping | 心跳保活，每10秒一次 |
| queue | 任务在队列中的状态 |
| progress | 任务进度更新 |
| completed | 任务完成 |
| error | 任务失败 |

**Response**: `text/event-stream`

---

### 3.3 获取任务详情

**Endpoint**: `GET /api/v1/analysis/{task_id}`

**描述**: 获取分析任务的详细信息和结果。

**认证**: Required

**Response** (200):
```json
{
  "task_id": "string",
  "platform": "bilibili",
  "video_id": "string",
  "title": "string",
  "author": "string",
  "cover": "string",
  "duration": 3600,
  "status": "completed",
  "queue_position": 0,
  "estimated_wait_seconds": 0,
  "result": {
    "summary": "string",
    "key_points": [],
    "chapters": [],
    "mindmap": {}
  },
  "transcript": "string",
  "current_step": "analyze",
  "message": "分析完成",
  "created_at": "datetime",
  "started_at": "datetime",
  "completed_at": "datetime"
}
```

**current_step 进度说明**:
| step | 说明 |
|------|------|
| extract | 正在解析视频信息 |
| download | 正在下载视频 |
| transcribe | 正在语音转文字 |
| analyze | 正在AI分析 |

---

### 3.4 获取任务状态（轮询）

**Endpoint**: `GET /api/v1/analysis/{task_id}/status`

**描述**: 非 SSE 方式获取任务状态，用于轮询。

## 4. 历史记录 (History)

### 4.1 获取历史记录列表

**Endpoint**: `GET /api/v1/history`

**描述**: 获取当前用户的历史分析记录（分页）。

**认证**: Required

**Query Parameters**:
| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| page | int | 1 | 页码 |
| limit | int | 20 | 每页数量 (max: 100) |
| group_id | string | null | 按分组ID筛选 |

**Response** (200):
```json
{
  "items": [
    {
      "id": "string",
      "platform": "bilibili",
      "title": "string",
      "author": "string",
      "cover": "string",
      "duration": 3600,
      "status": "completed",
      "created_at": "datetime",
      "group_ids": ["group_id_1"]
    }
  ],
  "total": 100
}
```

---

### 4.2 搜索历史记录

**Endpoint**: `GET /api/v1/history/search`

**描述**: 通过关键词搜索历史记录（搜索标题、作者、字幕）。

**认证**: Required

**Query Parameters**:
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| keyword | string | 是 | 搜索关键词 |
| page | int | 否 | 页码 (默认: 1) |
| limit | int | 否 | 每页数量 (默认: 20, max: 100) |

**Response** (200): 同 `4.1`

---

### 4.3 删除历史记录

**Endpoint**: `DELETE /api/v1/history/{task_id}`

**描述**: 删除一条历史记录。

**认证**: Required

**Response** (200):
```json
{
  "success": true,
  "message": "记录已删除"
}
```

**Error Response** (404):
```json
{
  "detail": "记录不存在"
}
```

## 通用错误响应

| HTTP Status | 说明 |
|-------------|------|
| 400 | 请求参数错误 |
| 401 | 未认证或认证失败 |
| 403 | 无权限访问 |
| 404 | 资源不存在 |
| 429 | 请求过于频繁 (队列满) |
| 500 | 服务器内部错误 |

```json
{
  "error": "ERROR_CODE",
  "message": "错误描述",
  "detail": {}
}
```
