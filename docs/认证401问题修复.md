# 401认证错误修复总结

## 🔍 问题分析

**现象**：
- 微信登录成功（200 OK）
- 游客登录成功（200 OK）
- 其他接口全部返回401 Unauthorized

**根本原因**：
- 后端验证：从cookie获取`session_id`
- 前端传递：通过Authorization header传递`auth_token`
- **验证方式不匹配** → 401错误

---

## ✅ 已完成的修复

### 1. 后端同时支持两种验证方式

**修改文件**: `backend/app/dependencies.py`

**新增逻辑**：
```python
async def get_current_user(request: Request, db: AsyncSession):
    # 方式1: 从cookie获取session_id
    session_id = request.cookies.get("session_id")
    
    # 方式2: 从Authorization header获取session_id（小程序支持）
    if not session_id:
        authorization = request.headers.get("Authorization")
        if authorization and authorization.startswith("Bearer "):
            session_id = authorization.replace("Bearer ", "")
    
    if not session_id:
        return None
    
    # 验证session并获取用户
    ...
```

**效果**：
- ✅ 支持Web端cookie验证
- ✅ 支持小程序Authorization header验证
- ✅ 兼容两种客户端

## 📋 完整认证流程

### Web端流程
```
登录成功 → 设置session_id cookie
    ↓
后续请求 → 自动携带cookie
    ↓
后端从cookie获取session_id → 验证成功 ✅
```

### 小程序流程
```
登录成功 → 返回session_id
    ↓
小程序保存到Storage: auth_token = session_id
    ↓
后续请求 → Authorization: Bearer session_id
    ↓
后端从header获取session_id → 验证成功 ✅
```
