# Omni-Notes 小程序重构设计文档

## 概述

基于新的设计系统（note-wx-design）对现有小程序进行 UI 改造，保留现有业务逻辑（API 集成、登录、数据管理），仅重构前端展现层。

## 技术选型

- 框架：微信小程序（原生框架）
- 样式：WXSS + 设计系统规范
- 状态管理：保持现有 Page/data 模式
- API：复用现有后端 API 服务
- 平台：仅微信小程序

## 数据模型约定

### 分组模型（简化版）
- 一个任务只属于一个分组
- 任务数据结构：`group_id`（单值，非数组）
- API 适配：前端使用 `task.group_ids?.[0]` 或 `task.group_id`

### 移除功能
- 收藏功能：已移除所有收藏相关界面和逻辑

## 项目结构

```
miniprogram/
├── app.wxss          # 全局样式（设计系统变量）
├── app.json          # 路由配置
```

## 页面设计

### 1. 首页（pages/index）

**布局结构**
```
[状态栏] - 微信原生
[导航栏] - 44px，品牌标识
[内容区] - 一屏展示，无需滚动
  ├── 品牌头部
  ├── 主标题
  ├── URL输入框
  ├── 平台标签（静态提示）
  ├── 固定底部按钮
  └── 能力展示区
[TabBar] - 60px，固定底部
```

**元素清单**
- 品牌头部：Logo（36px圆形） + Omni-Notes + AI 视频笔记
- 主标题：粘贴视频链接
- 副标题：AI 智能分析，一键生成笔记
- URL输入框：圆角12px，浅灰背景 #f8f9fc，左侧 + 图标
- 平台标签：B站（蓝）、抖音（粉红）- 静态展示
- 开始分析按钮：紫色渐变，固定底部，禁用时灰色

**交互行为**
- 输入框聚焦：白色背景 + 紫色边框 + 4px 阴影
- 无URL时按钮禁用（灰色）
- 有URL时按钮可点击（紫色渐变）

**WXSS 关键样式**
```css
.start-btn {
  background: linear-gradient(135deg, #7c3aed 0%, #8b5cf6 50%, #a855f7 100%);
  box-shadow: 0 4px 14px rgba(124, 58, 237, 0.35);
  border-radius: 12px;
  height: 48px;
}
```

### 2. 历史页（pages/history）

**布局结构**
```
[状态栏]
[导航栏] - "分析历史"（无右侧按钮，避免被系统返回键遮挡）
[搜索栏] - 圆角输入框
[分组标签栏] - 横向滚动，末尾有⋮管理按钮
[内容区] - 可滚动（无横向滚动，内容宽度适应屏幕）
  └── 历史卡片列表
[TabBar]
```

**重要更新（v2.1）**
- ⚠️ 导航栏：无右侧按钮，分组管理入口移至分组标签栏最右侧⋮
- ⚠️ 历史卡片：标题行增加"移入分组"按钮
- ⚠️ 横向溢出：`.page-container` 设置 `overflow-x: hidden`

**元素清单**
- 导航栏：仅标题"分析历史"
- 搜索栏：◉ 图标 + "搜索历史记录..."
- 分组标签：全部、未分组、[各分组]、⋮（点击打开分组管理面板）
- 历史卡片：
  - 标题行：标题（最多2行）+ "移入分组"按钮 + 状态标签
  - 要点列表（1-3条）
  - 元信息（作者 · 平台 · 时间）

**卡片交互**
- 点击卡片 → 进入详情页
- 点击"移入分组" → 打开分组选择面板
- 长按 → 操作菜单（查看详情、移动分组、删除）

**分组管理功能（必须完整实现）**
- 分组筛选（全部/未分组/各分组）
- 分组管理面板：编辑分组名称、删除分组、新建分组
- 卡片移入分组：点击卡片"移入分组"按钮

**状态标签样式**
- 已完成：绿色背景 rgba(16,185,129,0.1)，绿色文字
- 进行中：蓝色背景 rgba(59,130,246,0.1)，蓝色文字
- 失败：红色背景 rgba(239,68,68,0.1)，红色文字

### 3. 详情页（pages/analysis/detail）

**布局结构**
```
[状态栏]
[导航栏] - "分析详情"（使用原生返回）
[内容区]
  ├── 品牌头部
  ├── 视频卡片（支持左滑操作）
  └── Tab 内容区
[TabBar]
```

**元素清单**
- 品牌头部：Logo + Omni-Notes + AI 视频笔记
- 视频卡片：
  - 缩略图（带平台标识、播放按钮）
  - 视频标题 + 作者/时间
  - 左滑显示：重新分析、删除记录

**Tab 内容区**
- Tab头部：摘要、要点（含数量角标）、导图、字幕
- 摘要面板：标题 + 复制按钮 + 内容
- 要点面板：序号圆点 + 标题 + 时间
- 导图面板：标题 + 全屏按钮 + 图片
- 字幕面板：标题 + 复制按钮 + 列表（时间 + 内容）

**底部操作栏**（分析完成后）
- 左侧：当前分组信息
- 右侧：切换分组按钮

**分析状态展示**（进行中）
- 标题 + 耗时计时
- 视频卡片 + 分析进度
- 进度条 + 步骤指示器
- 当前步骤详情

### 4. 我的页面（pages/profile）

**布局结构**
```
[状态栏]
[导航栏] - "我的"
[内容区]
  ├── 用户信息卡片
  ├── 关于与帮助
  └── 底部留白
[TabBar]
```

**元素清单**
- 用户信息卡片：
  - 头像：60px圆形，渐变紫色背景 + "O"
  - 用户名：游客用户 / 昵称
  - 用户统计：分析次数、使用天数
- 关于与帮助：
  - 使用帮助 → 跳转帮助页
  - 关于 Omni-Notes v2.0.0 → 关于页

**样式要点**
- 用户卡片：白色背景，20px圆角，阴影
- 统计区域：上边框分隔，三项横向均匀分布

## 实施顺序

1. **首页** - 品牌区、URL输入、能力展示
2. **历史页** - 分组筛选、搜索、卡片列表、分组管理
3. **详情页** - 视频信息、Tab切换、左滑操作
4. **我的页面** - 用户卡片、菜单列表
